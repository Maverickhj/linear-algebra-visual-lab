# 可视化约定

## 组织与命名

一个 Visualization Unit 回答一个几何问题，位于 `visualizations/<id>/`。概念用 `vector-addition` 这样的英文 kebab-case；具体习题可用 `ch04-s02-exNN-short-name`，其中编号只能来自已核对的原题。ID 稳定，章节不作为上层目录。

每个 Unit 必需 `README.md`、`unit.json`，以及至少一种输出：

| 形式 | 约定入口 | 其他文件 |
| --- | --- | --- |
| 静态 | `figure.svg` | 可手写 SVG；程序生成则保留源码和重生成命令 |
| 交互 | `interactive.html` | 按需有 `model.js`、`view.js`、`style.css` 等本地文件 |
| 两者 | 上述两个入口 | 优先从同一模型和绘图逻辑导出 |

附加插图使用 `figure-<meaning>.svg`，静态资源放本 Unit 内。不要为了填满结构而创建空子目录。独立 HTML 指页面及其相对资源可复制、可静态托管，不强制单文件内联。

## 内容与元数据

`unit.json` 只保存索引所需的事实，使用 UTF-8 JSON：

```json
{
  "title": "向量加法",
  "dimension": 2,
  "status": "draft",
  "reference": "Gilbert Strang, Introduction to Linear Algebra, 5th ed., §1.1, printed p.3, Figure 1.1."
}
```

`title` 为非空字符串；`dimension` 为整数 2 或 3；`status` 为 `draft` 或 `ready`；`reference` 可省略或为空字符串。ID 从目录名取得，可视化类型从入口文件发现，不在 JSON 再写文件列表。没有全局登记文件。标题、维度、状态、教材定位不在 README 再维护一套表格。

README 至少保留以下二级标题，标题可加中文说明：

- **Topic**：具体讨论的对象、问题、符号和前提。
- **Mathematical Insight**：希望建立的一条几何直觉，解释图中什么关系支持它。
- **Visualization**：链接实际存在的图或 HTML；说明可修改的源码、重生成命令与依赖。
- **Usage**：默认例子、可调范围、观察顺序、边界和退化情形。
- **Validation**：手算或不变量、实际执行的检查、未验证部分。`ready` 表示作者已按本节检查，不表示教材答案经过第三方审阅。

教材定位在索引显示。引用默认指英文第 5 版；页码为书内印刷页码，PDF 查看器页码只能作为另行标明的辅助信息。教材结论、项目自选数值和推导应区分。未核对的编号不填，避免制造引用。

## 数学绘图与视觉

白色绘图区、浅纸色页面、深色文字、细灰坐标线；留白与关系优先于装饰。系统字体用于中文说明，数学标签用 serif。静态图和交互图采用相同语义与默认参数。

| 角色 | 颜色 | 补充标识 |
| --- | --- | --- |
| 页面 / 绘图区 | `#f6f7f2` / `#ffffff` | 正文与图分区 |
| 正文 / 坐标轴 / 网格 | `#172c36` / `#68777d` / `#e7ebe7` | 坐标轴比网格更明显 |
| 第一输入向量 `a` | `#2563a6` | 实线、文字 `a` |
| 第二输入向量 `b` | `#9c641d` | 实线、文字 `b` |
| 结果（和、变换结果或投影） | `#087d79` | 较粗实线、结果标签 |
| 误差 / 残差 | `#a14263` | 标签 `e`、按需点线 |
| 辅助关系 / 平移副本 | 继承对象颜色 | 虚线；不要只靠透明度区分 |
| 子空间面 | 结果色的浅色填充 | 标出边界及名称，说明绘制范围有限 |

这些是语义约定，项目不是全局主题引擎。初期每个 Unit 保留少量自己的样式；只有重复需求明确后才提取组件。色彩含义需要改变时在该 Unit 说明，并用文字、线型或标记补足。

- 二维：横轴 x 向右、纵轴 y 向上，原点明确，横纵同一单位长度。SVG 屏幕 y 向下，应显式转换，例如 `(cx + s*x, cy - s*y)`。
- 三维：右手坐标系，固定世界坐标的标签 x/y/z；区分视角旋转和数学变换。相机变化不能改动模型数值。显示投影方式（正交或透视），投影后的角度不能冒充空间中真实角度。
- 图中有限的线段、平面片是无限直线或子空间的视窗表示，必须标明；不能把坐标视窗当作数学定义。
- 向量箭头应有起点、方向和标签；零向量没有方向，使用点或圆环，不绘制虚假的箭头。
- 默认等比例；如需自动缩放，应公开当前范围，不用不同比例夸大关系。二维图不可把手机响应式压缩变成横纵不同缩放。
- 精确输入与显示舍入分开，容差需有依据。依赖非零、线性无关或可逆性的公式先检查条件；失败时说明原因，不输出 NaN。

## 交互

先呈现一个可手算的默认例子。控件说明参数含义、范围、步长和当前值；输入即时更新图形与读数，并提供重置。状态来自同一份参数，不让图与公式各自计算不同答案。

数字输入提供明确报错，保留最后一次有效图形；滑块提供键盘路径。拖动不是唯一操作方式。三维实验若使用旋转，应统一提供拖动旋转、方向键旋转、恢复视角；缩放有上下限，并和参数重置区分。

无时间变量的实验不提供播放按钮。动画确有意义时才加入，需可暂停并尊重 `prefers-reduced-motion`。窄屏自然堆叠，无页面横向溢出；颜色之外保留文字和线型区别，SVG 使用 `title` / `desc`，控件绑定 label，焦点可见。

## 技术基线与扩展流程

- **静态**：SVG 是首选可编辑产物。当前示例使用 Node 标准库调用纯绘图函数生成，不需要 npm 安装。后续有科学制图需求时可由该 Unit 选择 Matplotlib 等工具，并保存脚本、固定依赖与命令。
- **二维交互**：原生 HTML/CSS/JavaScript 与 SVG。数学模型不访问 DOM；视图把结果转换为图形，控制逻辑处理用户输入。
- **三维交互**：按具体问题选择简单的 SVG/Canvas 投影或随 Unit 保存的本地三维库；说明相机约定、版本与许可。本阶段没有实现三维渲染器，也没有三维示例，不为尚未提出的需求引入 Three.js。
- **数学排版**：Markdown 使用 `$...$` / `$$...$$`；当前简单 HTML 公式使用浏览器原生 MathML，SVG 内保留短标签。目标为现代 Chromium / Firefox / Safari；本次实际验证 Chromium。以后若需要复杂 LaTeX 排版，可在对应 Unit 引入固定版本的本地 KaTeX 与许可，禁止运行时 CDN。
- **运行**：页面用相对资源、classic scripts，不使用远程请求。Python 3.10+ 标准库提供工具和静态服务。额外开发依赖与阅读时依赖分开记录。

新增流程是 `new → 写数学说明 → 实现 → 手算与浏览器验证 → ready → check → index → Git 提交`。`new` 默认草稿，拒绝覆盖已有目录，并自动更新索引；静态、交互、两者均可独立选择。更改已有 Unit 后只验证相关数学，再执行全局结构检查并重建索引。无需修改框架或既有 Unit。

`check` 检查命名、字段、README 章节及可视化入口存在；它不检查数学正确性，也不替作者验证截图。浏览器应另查参数同步、错误输入、重置、退化情形、键盘、390px 窄屏、离线和资源加载。当前最小示例保存可重跑的检查。

## 设计依据

已检查参考仓库 [ai-infra-visual-lab，commit 096d1bb](https://github.com/Maverickhj/ai-infra-visual-lab/tree/096d1bb859778f85ebf47a9f4826764ae2bbd3c5) 的 README、`scripts/lab.py`、`registry.json`、`hub/`、`templates/experiment/`、`docs/MODELING.md`、`docs/MATH.md` 及验证说明。

| 实际实现 | 本仓库的选择 |
| --- | --- |
| Python 标准库 CLI；实验目录；原生网页 | 保留，简化到 new / check / index / serve |
| `registry.json` 集中维护元数据并生成目录 | 每个 Unit 一个 `unit.json`，扫描生成索引，减少集中编辑 |
| `dist/model.js` 纯计算与交互控制分开 | 保留模型分离，不引入通用运行引擎 |
| 浅纸色、深色文字、青绿色强调，参数与观察相连 | 保留视觉方向，增加等比例坐标、向量与辅助线约定 |
| 本地 KaTeX、完整实验副本和离线分发 | 保留离线与相对资源；当前 MathML 足够，无需拷贝整套公式库 |
| Sites 身份登记、云端发布、归档、导出下载包 | 当前不引入，用户本次仅要求 GitHub 仓库及基础框架 |
| 主要使用 HTML/SVG 动态渲染，无专门的独立静态插图流程 | 增加可编辑 SVG 入口；示例与交互共用绘图源码 |

本项目实现为重新编写；没有复制参考仓库的站点代码、实验内容、发布身份或 vendor 文件。
